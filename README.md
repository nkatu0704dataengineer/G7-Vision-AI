
# G7-Vision-AI

## 📌 Mô tả
Hệ thống Vision AI phục vụ nhận diện khuôn mặt trong điều kiện thực tế,
kết hợp:
- Fuzzy Logic (đánh giá chất lượng ảnh đầu vào)
- CNN (trích xuất đặc trưng)
- SVM (củng cố & tối ưu ranh giới phân lớp)
- KNN (so sánh đặc trưng trong CSDL và đưa ra quyết định)


## 🧠 Kiến trúc tổng thể
Fuzzy Logic -> CNN → SVM → KNN → Decision  

## 👥 Phân công nhóm
- CNN: Lê Minh, Văn Tùng
- SVM: Văn Minh
- KNN: Quang Tú
- Fuzzy Logic: Quân 
- Integration: Quang Tú
